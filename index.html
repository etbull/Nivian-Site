FAQ

Everything you need to know about our AI solutions

Australian privacy laws, including the Privacy Act 1988, require businesses to protect personal information. Hosting your AI in Australia ensures compliance with these regulations, keeps your data within Australian legal jurisdiction, and protects against foreign access requests. For industries like healthcare and legal services, this is often mandatory.

An MCP (Model Context Protocol) Server is something that allows an AI assistant to access and use your resources, apps and tools. It lets the AI Assistant access the apps you use (Like Xero, Salesforce, MYOB, odoo and more), and use that data in their responses. It also allows for granular access to your M365 resources, as well as the ability for your AI Assistant to start off autonomous AI Agents which can comlpete complex, multi-step tasks in the background.

An AI Agent is an AI model which can complete a task by taking input, access some tool, generate an output, then using this as input repeat the process until it reaches a conclusion. It can do things like get data from multiple sources, search your sharepoint, access a 3rd party API, and generate a report which it then emails to you. This is all hosted in Microsoft Azure, which uses an API from the AI assistant of your choice to do it's reasoning.

Nivian Assistants are hosted in your Microsoft Tenancy. We force Australian residency for all resources and enforce this with Azure policy to ensure compliance and peace of mind. We can also host in other regions if this is required. Contact us for more info.
